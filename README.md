# PulmanoryScreening
AI-powered breath analysis system for early lung cancer risk screening. Integrates mask-based breath chamber, sensor array, and lightweight ML models (Random Forest/LightGBM) to deliver rapid, non-invasive diagnostics within minutes. Designed for SIH healthcare innovation.
BreathGuard AI – Early Lung Cancer Risk Screening

This repository contains the source code, models, and documentation for an AI-powered breath analysis system designed to enable non-invasive, rapid screening of lung cancer risk.

🔑 Key Features
Breath Chamber Integration → Collects exhaled VOCs using a mask-based chamber setup.

Sensor Array Processing → Uses gas sensors (MQ-series, BME280, etc.) to capture chemical signatures.

Feature Engineering → Ratios, temporal patterns, and environmental compensation for robust signals.

Lightweight ML Models → Random Forest / LightGBM for fast, efficient inference.

Rapid Testing Workflow → End-to-end screening in ~5–7 minutes per user.

Deployment Ready → Optimized for laptops, Raspberry Pi, or edge devices.

📊 Project Goals
Provide affordable, accessible early screening for lung cancer risk.

Demonstrate AI + IoT integration in healthcare diagnostics.

Showcase hackathon-ready innovation with clear workflow and reproducible results.
